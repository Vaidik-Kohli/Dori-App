# Bharat Care - Demo App

This is the static frontend demo for Bharat Care. 

## How to run the Demo
Because this is a 100% hardcoded static frontend (optimized for live pitch presentations), there is no backend or database required.

Simply open the files in your browser (double-click them) in this order:
1. `dashboard.html` (Parent App)
2. `operator-console.html` (Operator Console)
3. `helper-app.html` (Helper App)
4. `nri-app.html` (Family Hub)

**The "Golden Path" Demo Scenario:**
- **Patient:** Anand Sharma (Delhi)
- **Helper:** Sunil Verma (Paramedic)
- **OTP:** 4092

When you click the huge SOS button on the Parent App, it will wait 5 seconds and automatically progress the demo to the OTP screen!
